# Using semantic codebase retrieval

## Change

I currently use `codebase-memory-mcp`. Its value is subtle in day-to-day work, but AI searches feel more trustworthy when the tool is available because it uses retrieval-augmented, semantic codebase search rather than relying only on ordinary string matching.

## Evidence

I continue to use the tool and have noticed an increase in confidence when AI investigates the codebase through semantic retrieval.

## Impact
